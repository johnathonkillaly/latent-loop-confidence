# Reproducing v0.2.0

Python 3.12, MLX 0.32.3 and mlx-lm 0.32.0 were used on Apple M4 Max. Install `python -m pip install -e '.[test]'` for CPU analysis, or `-e '.[apple,test]'` for Apple Silicon training. Exact dependencies are in `requirements-lock.txt`. No upgrade was needed for this release.

```sh
python -m pytest -q
LATENT_LOOP_MLX_TESTS=1 python -m pytest -q
python scripts/verify_public_reports.py
python -m latent_loop.experiment05.report
python -m latent_loop.planning report
```

Run each report generator in its own disposable checkout: derived audit timestamps/manifests change, and historical preservation hashes deliberately detect edits. Both new report generators audit public recorded logits and independently solve labels; no model weights or MLX are needed. HTML embeds figures. Historical reports and their source/config/data hashes are unchanged.

For actual model retraining follow [E5 commands](../reports/experiment_05/train_the_thinker.md#reproduction-and-local-status) and the [E5B detailed guide](../experiments/experiment_05b/README.md). E5B's statement that the branch is local describes its original pre-release status. Use a fresh isolated run namespace or disposable copy and fresh prospective protocols; do not overwrite consumed lockboxes. Preserve configurations, reset only generated manifests/outputs in the disposable rerun as documented. E5 requires regenerated historical pilot adapters for its transferred one-pass baseline. E5B grid and Snake training do not require Qwen.

Qwen3-0.6B revision `c1899de289a04d12100db370d81485cdf75e47ca` is downloaded separately under Apache-2.0. Seeds 11/22/33, split generator seeds, learning rates, depth objectives, checkpoint selection and optimizer settings are recorded in each experiment's configuration and frozen protocol. No BFS maps or labels enter learned-policy inference. Checkpoints/optimizer state are saved under ignored `artifacts/`; regenerate them for fresh inference, hidden-state extraction and interventions. Refit hashes may differ; do not pretend new checkpoints satisfy an old freeze.

Eight maze and three Snake datasets were previously regenerated byte-identically in a clean CPU environment; the receipts are retained. Public numerical audits check E5's 25,320 trajectory examples and E5B's 290,640 grid/Qwen decisions plus 18,000 Snake decisions. Full independent training replication and identical timing on another device are not claimed. Original E5/5B fitting and failures remain recorded.
