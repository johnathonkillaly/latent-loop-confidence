# Experiment 5 — Train the Loop, Not the Judge

Prospective local study, starting from public v0.1.0. No Experiment 5 changes may be pushed.

Primary hypothesis: shared lightweight middle-layer adaptation can make repeated frozen transformer computation improve conditional decisions beyond a comparably trained one-pass adapter. Better accuracy alone does not demonstrate reasoning.

Primary comparisons: validation-selected recurrent family at **fixed depth 4** versus the one-pass adapter at depth 1, and versus a one-pass control with additional optimization matched approximately to multi-depth training cost. Both use the same rank, data, seeds, preservation coefficient, and optimizer. Additional primary trajectory description: depth 2 minus depth 1, depth 3 minus depth 2, depth 4 minus depth 3 for the locked multi-depth family. Paired intervals resample unique problem instances jointly across models/depths and resample three training seeds. No multiplicity-adjusted claim is planned.

Conditions: A frozen Qwen3; B historical one-pass classifier (transfer reference); C untrained plain and bounded middle recurrence; D trainable one-pass LoRA; E variable-depth shared recurrence without reinjection; F E with bounded learned reinjection; G F with simultaneous equal-weight depths 1–4. One-pass additional-optimization control uses a prespecified cost-oriented epoch budget, fixed before main fits from pilot timings. E/F uniformly sample depth 1–4 per batch; neither trains only at deepest depth. G trains all four depths each batch. Common preservation KL applies only to examples the frozen model handles correctly, with alpha 0.02. No confidence-only reward or hard monotonic trajectory constraint.

Rank 8 is primary; rank 16 receives compatibility/count checks only unless rank 8 is technically nonviable. No exhaustive search. Three seeds 11/22/33 are planned. The small pilot uses 72 training and 36 validation examples, starts from scratch, and does not supply the main checkpoint. Main fits use fresh 576 training / 144 validation examples. Every task/approach/nominal difficulty cell is balanced. Final fresh ID has 288 items; five-shift final total is 864 items. Final sets are sealed and never selected by competence scores. Historical examples/alpha structures are exclusions only. Difficulty strata are generator descriptors, not established reasoning requirements.

Checkpoints minimize mean validation NLL across depths 1–4 for E/F/G, and depth-1 validation NLL for D. Family selection uses depth-4 validation NLL. All configurations, checkpoint hashes and selections freeze before opening the final lockbox. Eight-loop stress results are diagnostic only and cannot select depth/configuration. Reinjection removal/fixed-gate tests are inference ablations, explicitly distinct from separately trained controls.

The update gate starts open at 0.1; LoRA B starts at zero. First-depth logits match the original frozen model at initialization. Input reinjection is a token-local convex blend with an RMS-matched original pre-block anchor, bounded to 0.25. Additional-loop proposals are capped at twice the first-loop token norm and convexly mixed. No invalid KV reuse or changed positions; full-prefix recomputation is the initial implementation. Original Qwen GQA, QK normalization, RoPE and residuals remain in installed mlx-lm layers.

Pretraining checks: tiny and real-model depth-one parity, trained-prefix causality, position invariance, shared-gradient flow, frozen-weight checks, deterministic evaluation and adapter/optimizer restoration. Failing any blocks extension and training. Six-hour local budget, 48 GiB MLX allocation limit, and twenty-minute evaluation/report reserve. No unrelated process or remote workstation may be changed. Resumable optimizer/adapter checkpoints retain partial measurements.

Measure accuracy, conditional NLL, ECE/Brier, initial and adjacent correction/degradation, state norms/drift, gradient norms, task/stratum generalization, training throughput and synchronized full inference at batches 1/8. Report shared test items once, not as independent seeds. If recurrence does not beat the one-pass controls, make that the main result. C/V/D transfer, trajectory losses and loop memory are secondary/deferred unless useful fixed-depth computation justifies them.
