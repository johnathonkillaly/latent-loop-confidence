# Reproduce Experiment 5.2 locally

This experiment remains local for review. Do not push it or move public `v0.2.0`. See the [prospective plan](plan.md), [configuration](config.json), [freeze](frozen_protocol.json), [report](../../reports/experiment_05c/scaling_and_failure_frontier.md) and [public numerical audit](../../results/experiment_05c/public_audit.json).

Python3.12; MLX0.32.3; mlx-lm0.32.0; M4 Max. No new dependency was installed. CPU installation is `python -m pip install -e '.[test]'`, Apple fitting `-e '.[apple,test]'`. No pretrained model is loaded in this phase. Existing Qwen and Snake findings are preserved, with no new training.

```sh
python -m latent_loop.scaling --help
python -m pytest -q
LATENT_LOOP_MLX_TESTS=1 python -m pytest -q
python -m latent_loop.scaling audit
python -m latent_loop.scaling report
```

Audit/report need only public recorded measurements and CPU dependencies. They do not need model weights. All 10 dataset gzip files regenerated byte-identically in an independent CPU-only environment. Full independent neural retraining was not repeated. Exact inference on the 600 archived 5B ID examples was repeated for all three original checkpoints, with zero logit error.

Remove only new05c generated output/manifests/freezes/lockbox in that disposable copy; keep the original research checkout unchanged. Generate new run receipts. The historical baseline requires separately regenerated ignored `rec_simultaneous` and supplementary `rec_final4` checkpoints from [5B reproduction](../experiment_05b/README.md).
