# Experiment 5.2 — Break the Thinker

Prospective primary: unchanged 18,884-parameter 5B simultaneous planner, all three frozen seeds, eight minus four internal loops on 600 fresh branching 9×9 occupancy mazes. Equal counts in BFS-distance strata 2–4, 5–8, 9–12, 13–20, 21–32; fixed density sampled uniformly 0.30–0.45. No model-selection use of new final data. Primary is a difficulty-stratified diagnostic population, not a natural maze prevalence claim. Other size/depth/architecture/intervention comparisons are secondary exploratory tests. Final sets are generated into ignored sealed storage and opened only after all configurations/checkpoints freeze.

Training: 6,000 fresh mixed 5/7 boards, 30 epochs, batch64, seeds101/202/303, identical optimizer/data/update counts for all five conditions. Each size/path-bin cell receives equal count; curriculum resamples eligible examples, changing exposure but retaining update count. Variable depth samples1/2/4/8/16 uniformly. Curriculum: first10epochs distance≤8 loops1/2/4, next10 distance≤12 loops2/4/8, last10 all loops4/8/16. Checkpoint selection minimizes validation set loss at the prespecified deployment depth8 (FF4/global4). No auxiliary BFS-map loss. Report actual fit compute; equal epochs do not imply equal wall time.

Models: unchanged historical recurrent model; fresh variable/curriculum recurrence; narrow four-block parameter control; eight-block untied same-width computation control; four-block global CNN. Global control uses pooled spatial context plus goal/agent coordinate summaries (derived exclusively from raw board channels), disclosed as a stronger receptive field. Its parameter count and latency are measured, not assumed matched. All learned policies see raw four-channel boards, with no solver-derived input. Recurrent state resets per environment action. Each update remains one-hop except explicitly global control.

Depths1/2/4/8/12/16/24/32. Only the historical execution guard is extended in a new module; original model source and weights remain unchanged. Exact parity through16, finite/bounded32-loop states and real archived inference are prerequisites. No retraining/gate tuning of historical baseline. Validation must establish stability before training at16.

Leakage: D4 whole-wall hashes plus conservative unrooted reachable-component Weisfeiler–Lehman invariant exclude any previously seen fingerprint, including all historical 5B data, across all new splits. Isomorphic graphs necessarily share the invariant; every matching invariant is rejected even if it could represent non-isomorphic graphs. Fingerprint equality is not claimed to prove isomorphism. This conservative rule can reject distinct graphs and changes prevalence. New goal placements on the same topology are excluded across splits.

Rollouts: first six instances per configured path stratum, all three seeds, depths4/8/16/32 (static controls only their actual depth); max256 environment steps. Deterministic stateless policies terminate after a repeated position, because subsequent evolution is a proven cycle; report censor/termination rule. BFS only scores offline. Cycles are failure, not successful completion. Explicit reference BFS and greedy policies read boards; learned policies never receive reference outputs. No Qwen or Snake expansion.

Propagation: fixed ridge distance probes fitted only on training cells; held-out mazes are clusters. Goal ablation, graph-distance influence fronts, hidden-message cuts versus sham/no-goal interventions and paired far-goal same-board diagnostics are descriptive controls, not proof of learned BFS. No probe is deployed. Engineering frontier thresholds90% action/80% completion are descriptive, frozen before outcomes. Preserve all failed variants.

Budget:48GiB MLX, six active hours, save resumable model+optimizer and measurements at epoch boundaries. No workstation connections or unrelated process termination. Final results stay local and v0.2.0 remains immutable.
